# ブロック積擁壁 安定計算 Webアプリ

ブロック積（石積）擁壁の安定計算（転倒・滑動・支持力）を行う静的Webアプリです。
ビルド不要で、`index.html` をブラウザで開くだけで使用できます。

## 計算内容

技術資料「ブロック積（石積）擁壁安定計算」の計算例（H=3.768mのケース）と同じ手順で計算します。

1. **クーロンの主働土圧係数 K<sub>A</sub>** を、壁背面角・内部摩擦角・壁面摩擦角（δ=2φ/3）・盛土傾斜角から算出
2. **上載荷重の等分布荷重換算**：フローリッヒの地盤応力理論を用い、活荷重を盛土高に換算した上で等分布荷重 q<sub>w</sub> に換算
3. **(1) 転倒に対する検討**：示力線法により、各高さでの断面のミドルサード（中央1/3の境界位置）X' と、合力位置 X<sub>h</sub> を比較し、擁壁全高にわたって OK/NG を判定。安定最大高さ H<sub>max</sub> も算出
4. **(2) 滑動に対する検討**：滑動抵抗力 R<sub>H</sub> と全水平力 ΣH の比が必要安全率 Fs 以上であることを確認
5. **(3) 支持力に対する検討**：道路土工―擁壁工指針の直接基礎の考え方に従い、底面合力の偏心を考慮して地盤反力を算出。中央1/3内では台形分布、中央1/3外では引張反力を許容しない三角形分布として、最大地盤反力 q<sub>max</sub> が許容支持力度 q<sub>a</sub> 以下であることを確認

## 使い方

```bash
# ローカルで開く場合（例）
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

またはファイルをGitHub Pages等の静的ホスティングに配置してそのまま利用できます。

画面上部の「1. 設計条件」フォームに、裏込め土・壁体・載荷重・形状寸法・安定条件などを入力し、
「計算する」ボタンを押すと、下部に計算過程と判定結果、示力線図が表示されます。
初期値は技術資料の計算例と同じ条件になっており、「入力例に戻す」で初期値に戻せます。

基礎幅 B は既定では `b・cosecθ0` により自動計算されますが、実際の基礎（フーチング）幅が
別途決まっている場合は「基礎幅 B（手動指定・任意）」欄に数値を入力すると、その値で
支持力照査を行います。手動指定した基礎幅は、壁体底面の中心に対して左右均等に広がるものと
仮定します。

支持力照査では、壁天端中心から底面合力までの距離 `Xh(H)` と底面中心位置
`H・cotθ0` の差を偏心距離 `e` とします。`|e| ≤ B/6` では
`qmax,min = ΣV/B・(1 ± 6|e|/B)`、それを超えて合力が底面内にある場合は引張反力を
無視した三角形分布、合力が底面外にある場合は支持不能（NG）として扱います。

計算結果の上部にある「🖨 PDF出力（印刷）」ボタンを押すと、ブラウザの印刷機能が開きます。
印刷先を「PDFに保存」にすることで、技術資料の計算例と同じ体裁（擁壁名称・「１．設計条件」
「２．荷重計算」「３．安定計算」の章立て、数値代入式、示力線法の計算表・示力線図）の
PDFレポートとして保存できます（iPad・iPhoneのSafariでは共有メニューの「プリント」からも
PDF化できます）。擁壁名称は「1. 設計条件」欄の一番上で入力できます（未入力でも出力可）。

## ファイル構成

- `index.html` … 入力フォームと結果表示画面
- `css/style.css` … スタイル（ライト/ダークモード対応、レスポンシブ）
- `js/calc.js` … 安定計算のロジック（Node.js からも `require` して単体テスト可能）
- `js/app.js` … フォームの入力取得・計算実行・結果描画（表・SVG示力線図）

## 注意事項

本アプリは技術資料の計算例に基づく簡易計算ツールです。実際の設計・照査における
最終判断は、必ず有資格の技術者が行ってください。
